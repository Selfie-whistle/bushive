# **App Name**: BharatBus

## Core Features:

- Bus Route Search: Search for bus routes based on origin, destination, and travel date.
- Interactive Seat Selection: Display an interactive seat map for users to select available seats, showing gender for neighboring passengers.
- Booking Flow Management: Guide users through selecting seats, entering details, and finalizing boarding points. Show times in Indian timezones.
- Payment and Confirmation: Simulate payment process and show a detailed booking confirmation screen.
- Booking Management: Enable users to manage their existing bookings using their phone number.
- AI Itinerary Planner: Use Genkit to generate personalized travel itineraries based on preferences, budget, and time. This tool may also incorporate travel history.
- Firestore Integration: Store bus data and user bookings securely in Cloud Firestore.

## Style Guidelines:

- Primary color: Indigo (#4B0082) to reflect the trustworthy and reliable nature of travel.
- Background color: Light lavender (#E6E6FA), a very pale tint of the primary hue, for a calming and neutral backdrop.
- Accent color: Violet (#8F00FF), to bring visual interest without clashing, useful for interactive elements and highlights.
- Headline font: 'Poppins' (sans-serif) for a contemporary, precise feel. Note: currently only Google Fonts are supported.
- Body font: 'PT Sans' (sans-serif), to pair with Poppins. Note: currently only Google Fonts are supported.
- Use modern, line-based icons to represent travel actions, accenting with the primary color blue.
- Maintain a clean, structured layout for an intuitive booking experience.
- Incorporate subtle animations to enhance user engagement.
